# 🏀🏈⚽⚾ Game Day Showdown

A sports quiz party game for the family. One screen (computer or TV) is the scoreboard; everyone else joins from an iPad or phone.

## How to play
1. On the computer, open the game website and tap **Host a game**. Pick question types, game mode and length.
2. On each iPad or phone, open the same website, tap **Join a game**, and type the 4-digit code (or scan the QR code).
3. Pick a name, a sports player and a level:
   - **Rookie**: ages 4–6, questions are read out loud.
   - **All-Star**: 2nd grade and up.
4. Press **Start!** on the computer.

## Game modes
- **Steal the Ball**: right answers let you pick a ball for a surprise (points, x2, steal, swap, fumble).
- **Fast Break**: a points race with speed and streak bonuses.
- **Snack Shack**: run a stadium snack stand and earn coins.

## Notes
- Multiplayer uses [PeerJS](https://peerjs.com) (included in `vendor/`), so devices connect directly with no server to run.
- Add `?local` to the address to test several tabs in one browser.
- Questions live in `questions.js`.
